4. Abstract

The Academic Calendar Builder is a web application that displays and manages important academic dates such as semester schedules, examinations, holidays and events in one place. Students and faculty often have to depend on circulars, notice boards or PDF files to find these dates, which makes them easy to miss. This system gives users a clear and organized calendar view where they can browse events and filter them by month or category.

The application is built using HTML for the page structure, CSS for styling and layout, and Java for handling the event data and application logic. Administrators can add, update and remove academic events. The main purpose of this project is to make academic schedules easy to access, accurate and simple to manage.

5. Objectives

- To display all academic dates in a clear calendar format.
- To manage semester schedules, examinations, holidays and events in one place.
- To allow users to browse the calendar month by month.
- To filter events by month or category.
- To allow administrators to add, update and remove events.
- To reduce confusion caused by scattered notices and circulars.
- To apply HTML, CSS and Java to a real-world academic problem.

6. Features

- Monthly calendar view of academic dates
- Event categories: Semester Schedule, Examinations, Holidays and Events
- Filter events by month
- Filter events by category
- Colour-coded events for each category
- Event details such as title, date, category and description
- Add, update and remove events (admin)
- Upcoming events list
- Simple and responsive user interface

7. Modules

Calendar Display Module:
- Shows the calendar for the selected month.
- Highlights the dates that have events.
- Lets users move to the previous or next month.

Event Management Module:
- Lets the administrator add new academic events.
- Lets the administrator update or remove existing events.
- Validates event details such as date and category.

Filter Module:
- Filters events by the selected month.
- Filters events by category (Semester, Exams, Holidays, Events).
- Shows only the events that match the selected filters.

Event Details Module:
- Displays the full details of a selected event.
- Shows a list of upcoming events.

8. Concepts Used

HTML:
- Page structure using headings, tables, lists and forms
- Forms for adding and editing events
- Dropdowns for selecting month and category filters

CSS:
- Styling of the calendar grid and event cards
- Colour coding for different event categories
- Flexbox / Grid layout
- Responsive design for different screen sizes

Java:
- Classes and objects (Event, Calendar, EventManager)
- Encapsulation using private fields with getters and setters
- Collections (ArrayList, HashMap) to store events
- Conditional statements and loops for filtering events
- Methods for adding, updating, removing and searching events

- Exception handling for invalid inputs
- File handling to save and load event data

10. Working Principle

1. Academic events are stored with their title, date, category and description.
2. The user opens the web application and the calendar for the current month is displayed.
3. Dates with events are highlighted and colour-coded by category.
4. The user can move between months to browse the calendar.
5. The user can filter events by month or category.
6. The system shows only the events that match the selected filters.
7. The user can click an event to view its full details.
8. The administrator can add, update or remove events, and the calendar updates automatically.
